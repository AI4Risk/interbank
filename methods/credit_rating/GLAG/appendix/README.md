# Supplementary materials

Supporting materials for *Generative LLM-Augmented Graph Mining for Interbank Credit Assessment*.

| Material | Contents |
| --- | --- |
| [Supplementary information examples](supplementary_information.md) | Selected facts for three banks in 2023Q3, Bank B's generated summary, lending outlook, and reference facts |
| [Experimental settings](experimental_settings.md) | Node sets, rolling-quarter evaluation, information access, coverage, and traceability |
| [Baseline implementation](baseline_implementation.md) | Augmentation integration, graph encoders, and method-specific hyperparameters |
| [Generation prompts](generation_prompts.md) | Complete system and user message templates |

The example downloads preserve the original selected fact records and the original Bank B output. Fact identifiers are local to their source bank and reporting-period file. Concept names in the displayed tables follow the manuscript's shortened labels; the downloadable facts retain the source concept names.
